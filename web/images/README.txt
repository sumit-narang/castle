Drop castle photos here to add them to the map.

Name each file after the castle's id, replacing "/" with "_", and keep your
image extension. Example:
    castle id  way/1023389562   ->   file  way_1023389562.jpg
Allowed: .jpg .jpeg .png .webp .gif

Find the exact filename in the "Save photo as" column of castle_gaps.xlsx.
Then rebuild:   python3 run_pipeline.py --from overrides
